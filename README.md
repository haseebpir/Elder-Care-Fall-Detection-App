## ✨ Overview

**MyWisdom** is a HealthTech app built to keep elderly loved ones safe and connected. Using motion sensors and real-time alerts, it detects falls instantly and notifies caregivers — combining an easy, senior-friendly experience with a powerful caregiver dashboard.

---

## 💼 Why Families (and Clients) Love This

- 🚨 **Instant Fall Detection** — Automatically detects falls and alerts caregivers within seconds
- 🆘 **One-Tap SOS Button** — Immediate emergency alert with location, even without falling
- 👨‍👩‍👧 **Caregiver Dashboard** — Family members can monitor status and history remotely
- 💊 **Medication Reminders** — Gentle, timed reminders so doses are never missed
- ❤️ **Vitals & Activity Tracking** — Heart rate, steps, and daily activity monitored over time
- 📍 **Location & Geofencing** — Know if a loved one has wandered outside a safe zone
- 📞 **Video Check-Ins** — Simple, one-tap video calls between family and elderly users
- 🔔 **Smart Family Notifications** — Everyone stays informed without constant phone calls
- 🧓 **Senior-Friendly Design** — Large text, simple navigation, and minimal learning curve
- 🔒 **Private & Secure Health Data** — Sensitive health information protected end-to-end

---

## 🧱 How It Works

| Feature | Experience |
|---|---|
| **Detect & Alert** | Motion sensors detect a fall and instantly notify caregivers with location |
| **Check In Anytime** | Family members can check vitals, activity, and status in real time |
| **Stay Connected** | Simple video calls and messages keep everyone close |
| **Never Miss Care** | Medication and appointment reminders keep routines on track |
| **Respond Fast** | The SOS button connects to help immediately, day or night |

## 🛠️ Tech Stack (Under the Hood)

**Mobile App:** React Native (single codebase for iOS & Android, senior-friendly UI)
**Backend:** Node.js, TypeScript for real-time alerts and health data processing
**Sensors:** Motion & wearable sensor integration for fall detection and activity tracking
**Cloud Infrastructure:** AWS for secure, always-on, real-time monitoring

This stack ensures alerts are delivered **instantly and reliably**, when every second matters.
